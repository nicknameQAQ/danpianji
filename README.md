# 单片机课程设计与实例资料

本仓库汇集四个原始资料目录：`单片机课程设计`、`单片机课程设计2`、`单片机课程设计3` 和 `单片机设计实例350例`。资料包括 51 单片机与 STM32 的课程设计、源代码、仿真文件、电路图、文档和演示素材。

## 去重方式

按文件内容的 SHA-256 哈希比较，21,004 个原始资料文件中保留 10,348 个，省略 10,656 个完全相同的副本，减少约 1.55 GB。相同内容优先保留目录层级较浅、路径较短的文件。每个省略文件的原始路径、保留路径、大小和哈希见 [重复文件对照.csv](重复文件对照.csv)。原始资料目录中的 Git 元数据和 `.gitignore` 未作为课程资料收录。

去重可能使某些工程的相对路径缺少原来重复放置的依赖文件。需要使用原始目录结构时，在 PowerShell 中运行：

```powershell
.\恢复完整资料.ps1
```

脚本会在仓库旁新建 `单片机资料完整副本`，复制已保留文件，并按对照表还原所有省略的副本；不会改动仓库中的资料。也可以通过 `-OutputDirectory` 指定其他不存在的目标目录。

## 大文件

一张约 150 MB 的 BMP 使用 Git LFS 存储。克隆仓库并获取大文件时，需要安装 Git LFS，随后运行 `git lfs pull`。
